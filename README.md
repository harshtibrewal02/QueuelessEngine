QueueLess – Backend (FastAPI)

A backend service for a QueueLess Management System built using FastAPI, PostgreSQL, and SQLAlchemy ORM.
This system is designed to manage queues efficiently by reducing physical waiting time and handling requests in a structured, scalable way.

🚀 Tech Stack

Backend Framework: FastAPI

Database: PostgreSQL

ORM: SQLAlchemy

API Documentation: Swagger UI (auto-generated by FastAPI)

Language: Python

✨ Features

RESTful API architecture

Fast and asynchronous request handling

Database integration using SQLAlchemy ORM

Clean project structure for scalability

Automatic API documentation using Swagger

Easy to integrate with any frontend (React, mobile apps, etc.)

⚙️ Setup Instructions
1️⃣ Clone the Repository
git clone https://github.com/your-username/your-repo-name.git
cd your-repo-name

2️⃣ Create a Virtual Environment
python -m venv venv
venv\Scripts\activate   # Windows

3️⃣ Install Dependencies
pip install -r requirements.txt

🗄️ Database Configuration

Install PostgreSQL

Create a database

Update your database URL in .env or config.py

Example:

DATABASE_URL=postgresql://username:password@localhost:5432/queueless_db

▶️ Run the Application
uvicorn app.main:app --reload


Server will start at:

http://127.0.0.1:8000
